# رحلة الثبات — نسخة جديدة كاملة (مبنية ومختبرة من الصفر)

## الملفات
- `index.html` — التطبيق كامل، مبني من جديد بكود نظيف يستعمل `localStorage`
- `manifest.json` — إعدادات التثبيت على الشاشة الرئيسية
- `service-worker.js` — يخلي التطبيق يخدم بلا نت
- `icons/icon-192.png` و `icons/icon-512.png` — أيقونات التطبيق

## ⚠️ مهم: احذف كل شيء قديم أولاً

بما أن عندك نسخة قديمة مرفوعة على GitHub، اتبع هذي الخطوات بالضبط باش ما يبقاش أي تعارض:

1. روح لمستودعك على GitHub
2. **احذف الملفات القديمة كلها** (index.html, manifest.json, service-worker.js, ومجلد icons القديم) — من واجهة GitHub تقدر تحذف كل ملف بالدخول عليه والضغط على أيقونة سلة المهملات
3. ارفع الملفات الجديدة دول كاملة (Add file → Upload files) — اسحب كل الملفات مع الحفاظ على بنية مجلد `icons/`
4. Commit

## تفعيل GitHub Pages (إذا ما كانتش مفعلة)

**Settings** → **Pages** → **Source**: اختر **Deploy from a branch** → البرانش **main** والمجلد **/ (root)** → **Save**

## التثبيت على الشاشة الرئيسية

1. **احذف التطبيق القديم بالكامل** من شاشتك الرئيسية أولاً
2. Chrome → **Settings** → **Site settings** → دور على رابط موقعك → **Clear & Reset** (مسح كامل)
3. أغلق Chrome كليًا وأعد فتحه
4. افتح الرابط: `https://<اسمك>.github.io/<اسم-المستودع>/`
5. قائمة (⋮) → **Add to Home screen**

## كيف تتأكد أن الحفظ يخدم

كل مرة تعلّم صلاة أو ذكر أو تضغط "ثبتّ اليوم"، لازم يبان لك إشعار صغير أسفل الشاشة يقول **"✓ تم الحفظ"**. إذا ما بانش هذا الإشعار، فيه مشكلة — خبرني فورًا.

## إذا بدّلت أي شيء بالمستقبل

بدّل رقم النسخة في `service-worker.js`:

const CACHE_NAME = 'thabat-v2-fresh'; // زيد الرقم فـ كل تحديث
